# 02 — Аналитика Wildberries и Ozon

**Задача.** Магазин на двух площадках. Нужны ответы на вопросы: что реально продаётся по
артикулам, какая категория даёт выручку, какие товары есть на обеих площадках, какие отзывы
остались без ответа. Кабинеты такие отчёты дают неудобно, а сводную — не дают вовсе.

**Решение.** Набор CLI-скриптов на чистом Python: тянут данные через официальные API,
считают экономику и складывают результат в JSON/таблицы.

---

## Главная проблема, которую пришлось решить

Wildberries блокирует по IP за частые запросы — причём молча: не отдаёт `429`, а роняет
SSL-соединение по таймауту. Снаружи это выглядит как «интернет отвалился».

Всё, что выяснено опытным путём, зафиксировано в [`лимиты.py`](src/лимиты.py):

1. Методы отзывов — примерно **1 запрос в 11–12 минут** (сервер сообщает в `X-RateLimit-Retry`).
2. Нарушение ритма приводит к **блокировке IP** на часы, и каждая новая попытка её продлевает.
3. Блокировка не отвечает кодом ошибки — только таймаут рукопожатия.

Поэтому архитектура построена вокруг предохранителя:

```
mp_core.py   единый http_request() — ВСЕ запросы идут только через него
лимиты.py    минимальный интервал, пауза по Retry-After, полная остановка после серии сбоев
```

Ни один скрипт не обращается к площадке напрямую — физически невозможно «промахнуться» мимо лимита.

## Модули

| Файл | Что делает |
|---|---|
| [`mp_core.py`](src/mp_core.py) | единая точка HTTP: интервалы, обработка 429, длинная пауза при сетевом сбое, остановка после N сбоев |
| [`лимиты.py`](src/лимиты.py) | правила и константы лимитов, выведенные из практики |
| [`wb_экономика.py`](src/wb_экономика.py) | по каждому артикулу: продано, выручка, средняя цена, доля в выручке; сверка с Ozon |
| [`wb_категории_и_воронка.py`](src/wb_категории_и_воронка.py) | отбор SKU по категориям + аналитика воронки |
| [`reviews.py`](src/reviews.py) | неотвеченные отзывы WB и Ozon, публикация ответа |
| [`ozon_товары.py`](src/ozon_товары.py) | названия и картинки товаров Ozon для отбора категорий |

## Работа с отзывами: правило, а не удобство

Ответ покупателю публикуется **только после утверждения текста человеком**. Скрипт умеет
отправить ответ, но по умолчанию показывает список неотвеченных и ждёт. Причина: ответ от имени
магазина — это публичное обязательство, и «пусть нейросеть ответит сама» здесь неуместно.

## Стек

Python 3.11, **только стандартная библиотека** (`urllib`, `configparser`, `json`) — сознательно:
скрипты запускаются на минимальном сервере без зависимостей.

Ключи читаются из `keys.ini` (в репозиторий не входит, файл в `.gitignore`).

**785 строк.** Выгрузки и данные магазина в репозиторий не включены.
