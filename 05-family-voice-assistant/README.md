# 05 — Профиль «Ребёнок Алиса»: голосовой агент + расписание

**Задача.** Ребёнку — расписание уроков, будильник, напоминания о портфеле, вечерний контроль.
Все это — через голосовую колонку в доме, без ручных настроек. Нужно: работает без интернета
(модель на чипе или простые команды), не «гремит» каждый раз, и не зависит от облака.

**Решение.** Два файла на Python: `детский_агент.py` (команды текст/подъём/портфель/вечер) и
`будильник.py` (планировщик с сохранением состояния в JSON) + `edge-tts` (синтез речи)
для озвучивания. Без внешних API — только локальная колонка.

---

## Как устроено

```
детский_агент.py      ядро: читает расписание.json → генерирует текст → вызывает озвучить()
будильник.py          планировщик: проверяет время → запускает команды агента → запись состояния
```

**Команды агента:** `сейчас`, `завтра`, `подъём`, `портфель`, `вечер`, `скажи "текст"`.

**Озвучивание:** `edge-tts --voice=ru-RU-SvetlanaNeural` → `mp3` → `subprocess.run` проигрывания.
Если интернета нет — `edge-tts` не сработает, но само расписание и текст работают (только без голоса);
аварийный режим предвиден в архитектуре (облачный `cloudflared.exe` для туннеля в папке `скрипты/`).

**Будильник:** `время_подъёма()` + `проверить(предупреждение_за=15, тест=False)` → при приближении
запускает подъём. Состояние хранится в `будильник_состояние.json` (время, флаг, пройдено).

---

## Принципы из кода

- **Голос — не обязательное, а дополнение.** Расписание и логика работают без интернета.
- **Без внешних API для планирования.** Только `datetime`, `subprocess`, JSON-файл.
- **Состояние — в файле**, не в памяти, — перезапуск не сбрасывает будильник.
- **Команды текстом** — ребёнок может попросить «что завтра» или «положи в портфель».
